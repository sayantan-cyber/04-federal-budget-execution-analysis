# Excel dashboard

`federal_budget_execution_dashboard.xlsx` — top-15 agency execution dashboard built from validated CSV extracts:

- Cover sheet with title, data source, and refresh date
- KPI sheet: government-wide obligation rate, outlay rate, unobligated balance
- Agency table: PivotTable of execution metrics with slicers (fiscal year, agency)
- Charts: obligation-rate bar chart, YoY trend lines, Q4-share column chart

`formulas.md` documents every non-trivial formula (what it computes, why).
